- **Technical Notes:**
  - key ไม่เคยอยู่ใน argv/ไฟล์ในรีโป — ส่งทาง env ของ QProcess; เก็บ plaintext ใน HKCU ของผู้ใช้ (ponytail: DPAPI ถ้าต้องการ)
  - AI error ทุกชนิด → None → ใช้ผล OCR เดิม (ไม่มี AI = v1.0.4 เป๊ะ); stderr log แค่ชนิด error ไม่ log key
  - AI เรียกแบบ sequential: +latency ต่อภาพ — วัดจริงตอน user ทดสอบ; ช้าเกิน → thread pool
  - update-package **ใช้ได้** กับเครื่องที่ลง ≥0.9.7 (ไม่เพิ่ม pip dep — urllib เป็น stdlib)
  - ⚠️ รอ: ยืนยันชื่อ model จริง (Test connection) + model รับภาพได้ + user ทดสอบก่อน push (test-before-push)
